# DetailPro Frontend

Frontend application for **DetailPro**, a college project created for a car detailing service platform.

This repository contains the client-side part of the system responsible for the user interface, routing, pages, and visual presentation of the application.

## How to Run

Clone the repository:

```bash
git clone https://github.com/cptn3m012/DetailPro-Frontend.git
cd DetailPro-Frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application should be available at:

```text
http://localhost:3000
```

---

## Available Scripts
